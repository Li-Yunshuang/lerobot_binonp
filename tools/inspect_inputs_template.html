Grey rows exist in the data but do not reach the network under the current configuration. Which rows are read is set at training time; this table shows the campaign defaults.

The observation cloud is cropped to the capture workspace; the goal cloud is a synthetic transform of the initial cloud and is not cropped — matching deployment, where the goal cloud is built the same way. A goal near the workspace edge can therefore place a few green points outside the wireframe box. That is faithful, not a rendering bug.

Point clouds are drawn after the shared isotropic workspace rescale; the wireframe is the [−1, 1] box. Joint and action traces are raw values, left arm blue, right arm orange, playhead marking the current frame. The black arrow is goal_transform: object start centroid → goal centroid. All episodes shown are successful demonstrations.
